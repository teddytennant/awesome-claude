# Ultrareview
**Status:** preview (research preview)
**Provenance:** both (`commands/review/ultrareview*` in snapshot; shipped publicly since v2.1.111, 2026-04-16)
**Sources:** docs `ultrareview.md`, `code-review-local.md`; snapshot `commands/review/`; changelog 2.1.111 to 2.1.314

## Purpose
A deep multi-agent review in a cloud sandbox, where each reported finding is independently reproduced and verified. Started only by the user.

## Behaviour

### Invocation
1. `/code-review ultra` is the command. `/ultrareview` is an alias when available. Claude MUST NOT start it on its own.
2. No argument reviews current branch against the default branch, including uncommitted and staged changes.
3. A single word is a base (branch, commit or tag; fetched from `origin`, with closest-name suggestion) or PR reference (`1234`, `#1234`, `PR 1234`, URL for the current repo).
4. Longer text is a note that Claude relates to findings; the scope is unchanged.

### Requirements
5. MUST need a claude.ai account. MUST NOT work on Bedrock, Agent Platform or Foundry, or for ZDR or HIPAA-configured orgs. In those cases `/code-review ultra` runs a local review instead.
6. PR mode needs `github.com`. The launch checks that the connected GitHub account can read the repo (2.1.248). GHES users review local branches instead.
7. `/code-review ultra` and `claude ultrareview` MUST check workspace trust before running git (2.1.309, 2.1.314).

### Upload
8. Branch reviews bundle and upload repository state under cloud upload rules. Credential-like files stay local, including renamed copies such as `id_rsa copy` (2.1.280).
9. On macOS and Linux: symbolic refs left out; a symbolic current branch refused; git 2.31+ required; `--separate-git-dir` refused; partial clones sent as working-tree snapshots, and refused on older git when files are missing (2.1.285).
10. Upload failures MUST have specific messages and never suggest `git add .` (2.1.290, 2.1.299).

### Launch
11. A dialog MUST show scope with file and line counts, free runs left, estimated cost, and that local branch review may upload uncommitted changes to tracked files (2.1.283). Reviews then run in the background.
12. Diff limits: 500 files and 8,000 lines by default; the refusal gives limits, size and largest files (2.1.216).
13. Empty diff MUST refuse naming the case and offering a command (2.1.277). A first commit is reviewed in full after dialog confirmation only. Non-interactive runs refuse it.
14. No merge base falls back to all tracked files, with full clone and confirmation, and refuses in non-interactive sessions when there is no base (2.1.277). A checkout with no refs is refused (2.1.221).

### Billing
15. Pro and Max have 3 one-time free runs. After that, usage credits, typically $5 to $25. Runs count once the cloud session starts.
16. Paid launch needs usage credits on, and confirmation once per conversation. `/usage-credits` checks this.

### Tracking
17. Typically 5 to 15 minutes. `/tasks` lists, details and stops. Stopping archives the session and returns nothing.
18. Client waits up to 45 minutes (2.1.260).
19. Findings arrive as a notification. Claude reports when stopped on claude.ai, or not found after deletion or account switch.
20. The browser link was removed from output (2.1.286).

### Posting
21. `--no-post` is the default. Interactive selection **Run and post the findings to the PR as me** posts; `--post` preselects it.
22. Posting MUST make one plain comment from the user's connected GitHub account, ending "Generated by Claude Code", through Anthropic's API, directly when findings arrive (2.1.269). It requires the session to stay open.
23. Outcomes: Posted with link, Already posted, Failed with reason.
24. `claude -p '/code-review ultra'` exits before findings and posts nothing. It MUST stop without launching when billing credits would apply.

### Subcommand
25. `claude ultrareview [target]` MUST block, print findings to stdout, and progress to stderr (2.1.120).
26. Running it counts as consent to the fallback and billing. When Claude runs it through Bash, the whole-repo review is refused.
27. Exit codes: 0 complete, 1 failure, stop, timeout, or untrusted, 130 Ctrl-C.
28. Re-running starts a new review, using a run or credits.

## Configuration & interfaces
| Flag | Purpose |
|---|---|
| `--json` | Raw `bugs.json` |
| `--timeout <minutes>` | Default 45 |
| `--post`, `--no-post` | Post control; both means no post |
| `--trust-workspace` | Trust for this run; no value, so targets go first |

`CLAUDE_CODE_DISABLE_ULTRAREVIEW_TRUST_CHECK=1` disables the trust check for scripts (2.1.309).

## Failure modes & edge cases
- `Error: Workspace not trusted` when it cannot ask.
- Repo too large to bundle: prompts for PR mode.
- Git config file stops upload: short message naming the kind of file (2.1.290).
- Switched accounts: resume under the original account to re-attach.
