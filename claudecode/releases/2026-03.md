# Claude Code releases — 2026-03

Non-fix changelog entries, quoted from the public changelog. Each heading gives the version, its npm publish date, and how many fix entries were left out.

## 2.1.89 — 2026-03-31 (22 entries, 30 fixes omitted)

- `hooks` Added `"defer"` permission decision to `PreToolUse` hooks — headless sessions can pause at a tool call and resume with `-p --resume` to have the hook re-evaluate
- `tui-input` Added `CLAUDE_CODE_NO_FLICKER=1` environment variable to opt into flicker-free alt-screen rendering with virtualized scrollback
- `hooks` Added `PermissionDenied` hook that fires after auto mode classifier denials — return `{retry: true}` to tell the model it can retry
- `agents` Added named subagents to `@` mention typeahead suggestions
- `mcp` Added `MCP_CONNECTION_NONBLOCKING=true` for `-p` mode to skip the MCP connection wait entirely, and bounded `--mcp-config` server connections at 5s instead of blocking on the slowest server
- `permissions-sandbox` Auto mode: denied commands now show a notification and appear in `/permissions` → Recent tab where you can retry with `r`
- `tools` Improved collapsed tool summary to show "Listed N directories" for `ls`/`tree`/`du` instead of "Read N files"
- `tools` Improved Bash tool to warn when a formatter/linter command modifies files you have previously read, preventing stale-edit errors
- `mcp` Improved `@`-mention typeahead to rank source files above MCP resources with similar names
- `tools` Improved PowerShell tool prompt with version-appropriate syntax guidance (5.1 vs 7+)
- `tools` Changed `Edit` to work on files viewed via `Bash` with `sed -n` or `cat`, without requiring a separate `Read` call first
- `hooks` Changed hook output over 10,000 characters to be saved to disk with a file path + a 2,000-character preview instead of being injected directly into context
- `memory-context` Changed `cleanupPeriodDays: 0` in settings.json to be rejected with a validation error — it previously silently disabled transcript persistence
- `models-providers` Changed thinking summaries to no longer be generated by default in interactive sessions — set `showThinkingSummaries: true` in settings.json to restore
- `hooks` Documented `TaskCreated` hook event and its blocking behavior
- `other` Preserved task notifications when backgrounding a running command with Ctrl+B
- `tools` PowerShell tool on Windows: external-command arguments containing both a double-quote and whitespace now prompt instead of auto-allowing (PS 5.1 argument-splitting hardening)
- `tools` `/env` now applies to PowerShell tool commands (previously only affected Bash)
- `models-providers` `/usage` now hides redundant "Current week (Sonnet only)" bar for Pro and Enterprise plans
- `tui-input` Image paste no longer inserts a trailing space
- `other` Pasting `!command` into an empty prompt now enters bash mode, matching typed `!` behavior
- `tui-input` `/buddy` is here for April 1st — hatch a small creature that watches you code
